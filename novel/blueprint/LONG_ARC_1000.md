## 部落头子结构（锁定）

```
部落
 ├─ 大酋长 / 政治头子：萨尔（外交、元素、民心）
 ├─ 战争头子：格罗姆·地狱咆哮（征伐、荣誉战场）
 ├─ 神灵顾问：先知（洛戈什/先祖侧）
 ├─ 多族议事：暗矛、牛头、亡灵（后期）、血精灵（视线）
 └─ 对神庭：荣誉藩属 + 文化自治 + 必须有头子可问责
```

禁止：无主散沙、全员只会对主角摇尾。  
允许：头子之间路线斗争；主角可裁断，但部落仍是**政权**。
