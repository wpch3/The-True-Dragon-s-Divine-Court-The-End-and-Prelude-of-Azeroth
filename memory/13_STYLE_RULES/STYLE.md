# 文风与尺度

## 字数
- 正文章 2000–5000 汉字（可至 6000，禁注水）

## 节奏
- 武力 / 智斗 / 战场英姿 / 生活 / 家内 轮换  
- 大场面后必有消化章  

## 尺度（用户 D-C3）
- **保持 Gemini 风**：神庭家内可写修罗、侍奉、身体张力、露骨暗示到直白；  
- **不要**「在家里还相敬如宾」的过度克制；  
- 外事、朝会、兄弟线可切换庄重模式。  

## 无敌
- 不虐主；不伪弱；不靠更强 Boss 拖章  

## 部落
- 有头子；荣誉藩属；可斗争  

## 每章结尾
- 尽量带「卷年鉴/备忘」3–6 条，方便 memory 回写
