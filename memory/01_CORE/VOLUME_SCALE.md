# 体量标尺：不是「只能 500」，而是「能写多长就规划多长」

## 1. 结论

| 说法 | 对错 |
|---|---|
| 本书上限 500 章 | **错** |
| 500 是舒适的第一阶段里程碑 | **对** |
| 可以 800 / 1000 / 1200+ | **对，前提是蓝图与世界观先扩** |
| 变长 = 注水重复秒杀 | **错，禁止** |
| 变长 = 新地图·新种族·新故事弧·原著未写完的缝 | **对** |

## 2. 三层目标

| 层 | 章数（弹性） | 内容 |
|---|---|---|
| **L1 正史完成** | ~520 | 艾泽拉斯旧秩序终焉 + 星海序曲打开（书名第一层兑现） |
| **L2 星海纪元** | ~700 | 殖民、军团残廷、纳鲁矫正、外域稳态、新自治领 |
| **L3 不可思议** | ~900–1000+ | 虚空大君、万神殿重构、平行剪影、自创位面「真龙界域」、星魂完全人格 |

> 写到 L1 不完结也可以停；写到 L3 仍可开外传。**没有强制停笔章号。**

## 3. 变长的合法燃料（非注水清单）

1. 魔兽未写完/一笔带过的地区与故事集钩子  
2. 自创种族文明的完整兴衰（不是只跪一次）  
3. 自创地图：神庭本境层区、铸光圣域、潮廷、荣誉苑、星轨港、因果档案馆…  
4. 跨卷政治：部落头子权、圣王阿尔萨斯加冕、神庭法典修订史  
5. 职业与生活体系的「社会史」  
6. 女眷个人弧（每人可有独立小卷）  
7. 新故事：非原著事件（例：法则水晶战争、龙卵议会政变、渡亡司第一次公开审判）  
8. 维度外：悖论之女、维度游灵、他者宇宙使节  

## 4. 与「无敌」兼容

章数上升 **不** 要求更强敌人压主角。  
章数上升 = **舞台变多、文明变厚、因果余波变长**。  
详见 `blueprint/INVINCIBLE_500_STRATEGY.md`（七引擎）+ 本仓库 `LONG_ARC_1000.md`。

## 5. 门控（防止假长篇）

每一百章检查：

- [ ] 是否至少新增 1 个**有名有姓的地理/文明节点**？  
- [ ] 是否至少推进 1 条**非战力**主线？  
- [ ] 是否有女眷/头子/兄弟的**人物变化**（不是只跪）？  
- [ ] 是否出现重复「一章灭一神」超过 3 次而无余波？→ 违规，砍烈度
