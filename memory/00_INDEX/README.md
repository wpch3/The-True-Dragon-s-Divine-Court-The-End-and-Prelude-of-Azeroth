## 章节分区（与记忆分离）

```
novel/chapters/
  _canon_current/     # 当前正典阅读入口（扁平副本）
  vol_01_…_001-015/   # 卷一正文
  vol_02_…_016-029/
  vol_03_…_030-080/   # 当前主写
  vol_04 … vol_10/    # 预留卷目录
  vol_XX_补章精修/     # 插章、修补章专区（编号规则见下）
```

### 精修插章编号规则（用户拍板）

若第 N 章有瑕疵且需**补充章**而非原地覆盖：

1. 原 `N` 章可保留为「有瑕疵的历史稿」或轻修；  
2. 其后正文章节**顺延 +1**（旧 N+1 → 新 N+2……）；  
3. 新写的修补章占用 **N+1**，文件名标注 `补`：  
   - 例：`21_第二十一章_补_月神殿余波与暗夜行政.md`  
4. **必须**在 `memory/12_REPAIR_LOG/` 登记：旧号、新号、原因、影响的钩子。  
5. `_canon_current/` 只保留正典链，不留废弃号冲突。

> 若瑕疵很小（错字、一句盖章过满），**优先原地精修**，不必动编号。

## 体量结论（摘要）

- **不是只能写 500 章。**  
- 500 = 第一阶段舒适目标；**可扩至 800–1000+**。  
- 能写更长的前提 = **世界观与蓝图先扩**（新种族、新地图、新故事弧），不是注水。  
- 详见 `01_CORE/VOLUME_SCALE.md` 与 `blueprint/LONG_ARC_1000.md`。
